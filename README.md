# 揽乐 Lanyue

> 原名 MusicDL / 音乐下载器（v1.0.31 及更早的发布仍用旧名）

多平台音乐下载桌面应用，支持**网易云音乐**、**QQ音乐**、**哔哩哔哩**、**酷狗音乐**、**酷我音乐**、**咪咕音乐**、**汽水音乐**、**5sing** 共 8 个音源。

## What's New

- **MCP 本地服务** — 外部 AI Agent 可直接驱动本应用：搜索/歌词/歌单/入队等 17 个工具，仅监听 127.0.0.1 + 令牌鉴权（见设置页，默认关闭），含调用审计与一键接入配置
- **AI 助手（应用内）** — 说一句人话，助手调用本应用自己的 17 个工具去查、去下、去加歌单；它每回合都读到**此刻的应用状态**（在播哪首、队列里有什么、刚搜了什么），所以「再来一首类似的」接得住；写操作逐条要你确认，调用记录与 Agent 进同一份审计
- **AI 智能歌单** — 在「我的歌单」页说一句主题，AI 只从**你已经攒下的歌**里挑（最多 400 首候选），预览可逐条勾掉，点「存为歌单」才落库
- **AI 自然语言搜索** — 一句话描述想听的歌，LLM 改写成多关键词并行聚合搜索后合并去重（搜索栏 ✨）
- **转码响度归一** — 转码弹窗可勾选 loudnorm（统一 -14 LUFS，跨曲目音量一致）
- **WebDAV 云同步** — 多设备双向合并歌单/下载模板/下载历史（ETag 乐观锁，见设置页）
- **下载历史 SQLite 化** — `node:sqlite` 零依赖后端，即时落盘，旧 history.json 自动迁移
- **酷狗逐字歌词（KRC）** — 解密为逐字时间戳结构，同时兼容合成 LRC
- **换源 Range 预检** — 换源前对候选音源做可播性探测，不再逐个试错整条取流链
- **队列强化** — 分平台并发钳制（防源风控）+ 终态立即落盘（防丢任务）

## 功能

- 🔍 **多平台搜索** — 8 源聚合搜索 + 搜索历史 + ✨ AI 自然语言搜索（需配大模型 API Key）
- ⬇ **高品质下载** — 支持标准 / 高品质 / 无损（视平台授权），分平台音质设置
- 🏷 **ID3 元数据** — 自动嵌入标题、艺术家、专辑、封面图、歌词
- 📝 **歌词下载** — 自动获取 LRC 歌词并生成独立文件；酷狗支持逐字歌词
- 🎵 **内置播放器** — 试听、歌词滚动、EQ 均衡器、桌面歌词、Media Session
- 📋 **下载队列** — 并发可控 + 分平台限流，进度实时显示，重启续传
- 🔀 **智能换源** — 取流失败自动跨源换源（Range 预检 + 源健康度排序）
- ❤ **歌单与收藏** — 用户歌单、红心收藏、订阅更新追踪
- 💾 **云同步** — WebDAV 快照多设备合并；手动导出/导入 JSON 备份
- 🤖 **MCP 服务** — 本机暴露 MCP Server（Streamable HTTP），AI Agent 可搜索音乐、查歌词、加下载队列、管理歌单；令牌桶限流 + 本机调用审计
- 🪄 **应用内 AI 助手** — 侧栏「AI 助手」用同一张工具表白名单干活（需先配大模型 API Key），改动曲库/队列的动作执行前逐条弹确认
- 🎛 **多厂商大模型配置** — AI 创作页与助手页共用一处面板：MiniMax / DeepSeek / 通义千问 / Kimi / 智谱 GLM / 豆包，外加自定义 OpenAI 兼容端点；每家的 Key 存在同一把加密映射里（换厂商不会抹掉别家凭据），音乐合成仍只有 MiniMax 提供，选别家时该按钮如实置灰
- 🧠 **AI 智能歌单** — 「我的歌单」页顶部 ✨：一句主题 + 挑选范围（全部歌单 / 只看红心 / 某一单），AI 现场从你已有的歌里挑并起名，预览逐条可勾，只有点「存为歌单」才写库
- ⬆ **自动更新** — GitHub Releases 检查与安装

## 快速开始

```bash
# 安装依赖
npm install

# 开发模式运行（含 DevTools）
npm run dev

# 正式运行
npm start

# 构建前端产物（vite + postbuild，不生成安装包）
npm run build

# 打包（Windows 安装包）
npm run package
```

## 目录结构

```
music-downloader/
├── src/
│   ├── main/            # Electron 主进程（下载队列、各 IPC 模块、更新器）
│   │   └── ipc/         # 按域拆分的 IPC 处理器（下载/历史/云同步/歌单…）
│   ├── api/
│   │   ├── platforms/   # 8 个平台插件：自描述 manifest + 检索/取流/歌词实现
│   │   ├── gateway.js   # 平台无关调用网关（能力推导 / 限频 / SSRF 白名单）
│   │   └── pluginRegistry.js  # 插件注册中心（单一事实来源）
│   ├── renderer/        # 渲染层（原生 ES Module，无框架）
│   └── utils/           # 下载器 / SQLite 历史 / 歌词解码 / WebDAV 同步等
├── test/                # node:test 单元/集成测试（npm test）
├── build/               # electron-builder 配置与安装图
└── package.json
```

## 依赖

| 包 | 用途 |
|---|---|
| electron | 桌面应用框架 |
| electron-updater | GitHub Releases 自动更新 |
| music-metadata | 音频元数据读取（MP3/FLAC/M4A 全格式） |
| NeteaseCloudMusicApi | 网易云音乐 API |
| qq-music-api | QQ 音乐 API |
| node-id3 | MP3 ID3 标签写入 |
| iconv-lite | GBK 编码歌词解码（Windows 兼容） |

> 数据库使用 Node 内置 `node:sqlite`（Electron 内嵌 Node 24 起支持），零原生依赖。
